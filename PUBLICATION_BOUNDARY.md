# Publication Boundary

This repository intentionally includes only the open task bank.

Included: statements, public inputs, output schemas, structural difficulty, non-answer solution
outlines, provenance and licensing records.

Excluded: administrator controls, correct/incorrect reference artifacts, hidden judges, sham break
definitions, per-run arm prompts and assignments, server paths, raw logs, credentials and private
evaluation instances.

The original administrator repository was frozen separately before this clean public history was
published. Its location and contents are not part of the public contract. Future blind/Pilot scores
must use new private instances because previously public evaluation material cannot be made secret
again by rewriting Git history.
