# Dataset Card

## Summary

ReturnBench-150 contains 150 public mathematical representation and certificate tasks selected from
discrete mathematics, algebra, geometry, probability and statistics, optimization, theoretical
computer science, coding, numerical analysis, signal processing, mathematical physics and control.

## Intended uses

- reproducible research on certificate-producing mathematical systems;
- representation-conversion and verifier integration research;
- qualitative error analysis and tool-routing experiments;
- development and validation against the public contracts.

## Out-of-scope claims

- The public static set is not contamination-free.
- Public-set performance is not a blind Pilot result.
- Structural difficulty is not a model score.
- Absence of a public reference answer does not make the already published statement a secret test.
